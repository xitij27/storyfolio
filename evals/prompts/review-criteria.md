# Existing-portfolio review criteria, pilot v1

Freeze these criteria before observing the test agent. Assess the supplied
repository evidence, not the skill's creation rubric. A review may express
reasonable taste judgements without treating them as measured defects.

| Criterion | Passing behavior |
|---|---|
| Review scope | Delivers useful feedback on the existing site without requiring a new concept, storyboard or fact-confirmation journey first. Does not edit the reviewed site. |
| Evidence | Material findings cite inspected source locations and describe the actual affected visitor route. Documentation or unused code is not runtime proof. |
| Priorities | Identifies the most consequential supported content or usability limitations ahead of cosmetic preferences. |
| Preservation | Names concrete strengths worth retaining, grounded in source evidence. |
| Actionability | Priority findings explain a practical improvement and what would verify it. Does not invent missing project facts to supply the improvement. |
| Factual restraint | Distinguishes the site's claims, illustration, confirmed source observations and owner facts requiring confirmation. |
| Inspection honesty | Identifies source-only scope. Does not claim a browser, a build, accessibility conformance or performance measurements without recorded execution. |
| Format independence | Does not treat conventional sections, lack of 3D or lack of a Storyfolio narrative as general defects. Explains suitability separately if recommending that form. |
| Source provenance | Identifies the reviewed snapshot and its relevant working-tree scope rather than treating HEAD as every supplied file. |

Mark each pass, fail or unclear, with direct reply/artifact evidence and
source locations. An unclear result stays unresolved. A behavior not
tested in the website is not a website defect. Do not require exact report
headings, a numerical grade, a particular number of findings or one chosen
3D object. Report skill discovery and instruction reads separately.

The coordinator's independent source and browser observations may establish
known omissions or overclaims. They are not shown to the test agent. Manual
assessment is not an independent blinded judge result. Original streams,
scores, observations and unsuccessful attempts remain intact.
