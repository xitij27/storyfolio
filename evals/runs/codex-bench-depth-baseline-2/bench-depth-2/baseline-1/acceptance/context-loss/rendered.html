1 / Code → physical check

How does code become a physical check?

3 / Open the bench

Make the board accessible.

A firmware command asks the physical board to act. The bring-up fixture provides access so that its response can be observed on the bench. The fixture helps check behavior; the board’s circuitry still performs the device’s work.

Ada: firmware, power-state scheduling and bring-up fixture. A colleague: the PCB (printed circuit board) and analogue front end, the circuitry interfacing with sensor signals.
