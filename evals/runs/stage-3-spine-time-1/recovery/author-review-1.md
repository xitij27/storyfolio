# Author review 1: why the site is "the same 3d asset roaming around"

22 October 2026. The author's verdict is recorded verbatim in
[the history record](../../../../docs/history/2026-10-22-author-review-first-reaction.md).
Root read the agent's own plan in the turn-6 workspace
(`journey-recovery-time-6-6k01cZ/docs/story/`) to find where it went wrong.

## What the agent planned

- **The object** is seven blocks of a generic bring-up fixture, each labelled
  with a role: Firmware, States, Command, Fixture, Observe, Estimate, Run
  (`concepts.md`, concept 1).
- **The faces** carry those role words, and in a few beats short phrases
  ("Two-year projection", "Longest run 72 hours", "40 engineering samples").
  The two supplied teaching drawings go on a face "if legible".
- **The formations** are, beat after beat, one group stepping forward or
  apart while "the other segments remain at the fixture base": responsibility,
  command, access, observe, battery and scope all use this move.
- **The plan forbids drawing confirmed facts**: "No bar lengths ... or
  proportional two-years/72-hours scale" (record.battery); "No forty-item grid
  or six 'successful' device icons" (record.scope); no animation of the loop's
  order in observe.open.

## Why that makes it roam

1. **Faces name categories, not the work.** "Observe" or "Command" on a block
   tells a visitor nothing; the skill asks for the person's real pictures and
   words. With the faces also unreadable at the size shown (the whole-site
   Detail failure), the pieces carry nothing at all.
2. **"One piece steps forward" is emphasis, not a form.** The skill asks for a
   new arrangement that shows what the chapter is about (a map, a diagram, an
   exhibit). Moving emphasis between labelled blocks shows only that the
   subject changed.
3. **The no-invention rule was read as "draw nothing".** Forty samples with six
   bench-tested, and a 72-hour run against a two-year projection, are
   confirmed facts. Drawing them at their true proportion invents nothing;
   inventing a value the fact sheet lacks (a duration, a current) would. With
   no photographs supplied, drawing the facts is the only thing the 3D could
   show, and the plan ruled it out.
4. **The concept was chosen for caution, not for what it could show.**
   Concept 2 (seven modules: Firmware, Sleep, Measure, Transmit ...) could
   have run the power-state loop as the scroll and shown the reported fault
   (radio still awake after a failed transmission) as that loop breaking.
   Concept 1 was chosen because it needed "less abstract mapping".
5. **The check could not see it.** The visual criteria measure rendering and
   motion; none asks what a formation says with the captions hidden.

## Candidate skill changes from this run

Proposed, not yet made; each is backed by the items above.

- Storyboard: each beat states what a visitor learns from the scene with the
  caption hidden. A beat whose answer is only "the subject changed" (one piece
  steps forward, a label changes) is not a formation.
- Storyboard: drawing a confirmed number, order or proportion is not
  invention; inventing a value is. Draw the facts when there are no pictures.
- Concept: choose among concepts by how many chapters the object can show
  something true in, not by how little it risks.
- Faces carry the work or a drawn fact, readable at the size shown, never a
  category name (with the earlier Detail finding).
- Whole-site check: a captions-hidden criterion per beat.
- Carried over: page chrome stays off the object; supporting pages after the
  look choice.

Per the repository rules, the runs this is made for are made again after
the change; the cheapest that tests all of it restarts at stop 2 (concepts)
on the same fixture.
