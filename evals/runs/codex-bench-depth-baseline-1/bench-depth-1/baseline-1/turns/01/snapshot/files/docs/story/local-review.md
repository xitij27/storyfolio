# Local prototype review

Run `npm run dev` and open its local URL. Production evidence is generated
by `npm run check`, which starts and stops its own production server.
The Node and browser setup is recorded in `environment-setup.json`.
Dependencies can be restored without external requests with
`npm ci --offline --cache=/tmp/storyfolio-npm-cache` in this evaluation.

Review the question, scheduling, bench relationship, separated evidence
paths and bounded answer in order. The apparatus is illustrative. Read the
HTML for all claims and limits; scene labels are not original lab evidence.
Use Tab and Enter for the skip link, chapter navigation and return link.
Emulate reduced motion, disable WebGL or JavaScript, or lose the WebGL
context to inspect complete fallback explanations. Phone screenshots are
viewport emulation, not physical-device performance or a real phone review.

`node scripts/review-sheets.mjs checks/<run>` makes contact sheets from the
screenshots already captured, using only installed Playwright. The detailed
results and the visual inspection record are in `handover.md`.
