# Original-image review of the three failure modes

11 October 2026. All 48 originals in `acceptance-2/no-webgl`,
`acceptance-2/no-javascript` and `acceptance-2/context-loss` were opened with
`view_image` at original resolution. Each mode has five mid captures, five
rest captures and six control captures. Duplicate image hashes were still
opened by their individual file paths. The complete [viewed inventory](viewed-images.json)
records each path, byte count and SHA-256. No contact sheet substitutes for
an original in this review. All three mode reports now exist.

The [read-only verification](verify.mjs) and its [result](verification.json)
bind those 48 files to the completed acceptance manifest, their mode
reports and source digest
`a2e81366eefe18dbb816dfa2f4ec239d684e3ff5d728382706bddc715e2da841`.
The before/after acceptance source records are identical. All 201 retained
actor snapshot files in the comparable source scope match their actual
snapshot bytes and acceptance source hashes.

The source sets are not exactly equal. Acceptance also includes 189 files
from the actor-created `.prototype-history/` Git directory, which its
snapshot omitted. The initial exact-set assertion [failed](initial-verification-failure.json).
The revised audit preserves that difference explicitly, checks every extra
file against the identical before/after records and current runtime bytes,
and lists all extra paths and hashes. Those metadata bytes are not retained
in the actor source snapshot. This limits exact source-set reproducibility;
no exclusion, frozen artifact or actor source was rewritten to erase it.
