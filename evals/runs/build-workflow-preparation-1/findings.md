## Final freeze is deferred

Two planned gates prevent treating this as a launch-ready cohort:

1. [Engine reproduction](engine-risk-result.json) confirms that the current
   `Story` provider covers HTML but not a scene consumer of `useControl`.
   The real modules throw in the deterministic context test, while HTML
   and outer-provider controls pass. This is a React server-rendered probe
   with a scene stand-in, not a new WebGL integration test. Fixed portrait
   texture sizes also reproduce a 4:1 uncompensated pixel-circle stretch
   on a 3:1 surface. Custom drawing can compensate. A separately reviewed
   shared-controls fix and browser verification are needed; no shipped
   engine or accepted prototype code was changed here.
2. [Transport calibration](transport-result.json) reconstructs two complete
   historical packets, preserving every supplied source/tool/report body.
   The 841,035-byte spine packet fits. The 2,560,105-byte completion packet
   is also 2,556,184 UTF-16 code units, above both current limits. Historical
   sizes do not forecast a new five-beat result. Synthetic exact-boundary
   tests remain in the suite, and actual post-run dry validation is still
   required. A separately scoped lossless transport decision is needed;
   no truncation, retry, raised allowance or new accessor was implemented.

The historical packets preserve their original selection policy, which
omitted acceptance logs and rendered HTML bodies. New schema-2 delivery
includes those textual artifacts too. The fitting old packet is therefore
not a proof that current diagnostic delivery fits. All delivered acceptance
source hashes now bind to the final saved actor snapshot, and transitive
capture code is frozen for prospective legacy cases as well as this one.
Existing historical cohorts and their frozen implementations stay intact.

Consequently `codex-bench-depth-baseline-1` is reserved but unprepared.
No final input digest, actor workspace, CLI/disabled-skill inventory or
actual loopback/external-denial/build/browser environment proof is claimed.
Those belong to the eventual post-decision freeze, not today's known-bad
engine and unresolved delivery policy. A read-only draft-input digest is
not a final freeze or permission to spend model usage.
