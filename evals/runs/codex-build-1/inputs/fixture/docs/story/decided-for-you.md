## Other explicit choices

- Keep the selected six-row State by state form, six chapters and seven
  beats. Eight desktop viewports are a budget, not a reason for blank
  mobile screens. This is a card regression, not a new object-family proof.
- Replace the missing fixture photo with an honestly labelled explanatory
  schematic. Use the supplied teaching diagram without claiming real
  firmware topology or measured timing. No private circuitry or trace.
- Use system sans-serif and monospace fonts because no licensed named
  font files are supplied. Keep all three appearances available for the
  spine's actual choice and subsequent review.
- Use static HTML and drawings on narrow screens, under reduced motion,
  without JavaScript or without working WebGL. Normal desktop still uses
  a six-piece scroll scene.
- Include no unconfirmed employment chronology, incident resolution,
  influence story, certification, field results or extra projects.
- Keep source and permission records, test results and handover notes in
  the local project. Publishing and external messages remain outside scope.
