# Ada Mensah — local concept studies

These are three concept sketches, not the completed portfolio. No concept or storyboard has been approved yet.

From this directory run `npm run dev -- --hostname 127.0.0.1`, then open:

- http://127.0.0.1:3000/ — comparison
- http://127.0.0.1:3000/sketch/fixture
- http://127.0.0.1:3000/sketch/dial
- http://127.0.0.1:3000/sketch/rack

Dependencies already installed from the supplied local npm cache. System fonts and local geometry only. The dev launcher disables framework telemetry and rejects external Node fetches, including framework version checks. Nothing has been published. Actual project photos, circuitry, traces and firmware are not included.

`node scripts/check-concepts.mjs` starts and stops its own local server and captures opening/middle/end at desktop and phone widths with reduced motion and software WebGL. Its executable/library paths are specific to this environment. This is a concept review, not full final acceptance or real phone performance measurement.

Story/fact/decision records are in `../docs/story/`. After concept choice, approve the full storyboard before implementing the selected portfolio. Final deliverables still include Mosslink's project page, downloadable printable HTML CV, share preview, icon and useful 404.
