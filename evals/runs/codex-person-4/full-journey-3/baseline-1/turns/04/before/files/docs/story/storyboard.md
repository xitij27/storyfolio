## Map-specific correctness and review limits
The world switch is implemented by changing only `content/mix.ts`; no library, facts, style or copy changes were made in this turn.

1. **University placement defect:** current map resolves `study.place` as an exact city name. “Entoto Technical University” is not a city entry, so the existing component falls back to Rotterdam. 2. **Portfolio hub versus event location:** all six existing work entries are anchored at Rotterdam. This can group the portfolio visually, but it does not establish that SRE North took place there. The current generic window uses project.place as a location label; suppress the unconfirmed talk-location claim during the detail/wording build while retaining its map hub. No venue needs to be invented or asked for.
3. **Readability:** the existing map prints long school/role names and fits broad career/skills views. Inspect actual phone and short-screen shots; any unresolvable tiny text must be in HTML rather than relied on in the picture. A nonblank screenshot is not a readability pass.
4. **Working illustration:** the selected gallery map draws the life route and opens work cards. It does not simulate a cutover, checksums or gated service movement. Keep the storyboard truthful about that capability; a project-specific working model would be a later requested component, not an unapproved replacement of the chosen map.
