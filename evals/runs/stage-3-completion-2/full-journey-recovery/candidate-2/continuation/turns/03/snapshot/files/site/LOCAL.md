# Local preview

From this folder, use:

```bash
npm run dev:local
```

Open http://127.0.0.1:3000. The root compares three concept sketches; selected concept A is at /sketch/fixture. These are review sketches, not the completed portfolio.

This command uses installed cached dependencies, disables telemetry and runtime registry repair, removes proxy variables for this preview process and binds to loopback. No deployment or external assets are required. System fonts and supplied local teaching drawings only.

Story decisions and current review status are in ../docs/story/handover.md. Storyboard approval is the next step; Mosslink project page, downloadable printable HTML CV and other planned routes will be built with the approved site.
