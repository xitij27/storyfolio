# Recovered stop-2 concept measurement

This is a separately amended, no-model measurement of candidate-2's
post-closure recovery checkpoint. It is not an unmodified frozen comparison
and does not establish the missing application identity at the original
turn-2 closure instant. Root owns review, records, commands and gates.
Source preparation alone grants no continuation or pass.

The normally completed original turns, 149 frozen inputs, 23 measurement

## Narrow differences

`amendment-lib.mjs` binds both original successful actor recorders, terminal
tool results, all 199 and 204 original artifacts, frozen inputs and original
implementation hashes. It requires the exact reviewed recovery timestamp,
manifest, 182-file archive and live source identity before reconstruction or
capture. The source exclusions and byte/file limits are unchanged. `.aws`
and `.codex` are explicitly checked as empty unexpected directories; they
are not general exclusions. The optional later runner uses the same common
validator, separately requiring immediate predecessor identity.

`prepare-source.mjs` copies every recovered source file to a new exclusive
temporary workspace, then compares the entire inventory. `site/` is only
the package/install/build/server cwd. Source guards always cover its sibling
files too. App components, package files and archive paths cannot be
symlinks; missing, changed or additional source blocks the measurement.

The gate worker is derived from the original, with import/cwd/lineage
changes and one source-demonstrated chooser initialization correction.
The original opens the destination and searches there for a selector that
may exist only on the declared source route. `choice-activation.mjs` instead
opens `control.fromRoute`, applies an explicitly declared real preparation
control if present, then validates and clicks the actual target. A fake-page
test first reproduces the old absent destination selector, then checks the
correct source-route interaction. Shared-page state choices are covered
too. Missing/renamed controls remain errors. Entry screenshots still record
the destination; the original separate pointer and Tab/keyboard trials,
geometry checks, response observations and failure assessment are retained.

No concept is omitted: root's source-bound targets retain all advertised
concepts and the observed navigation/appearance aliases. The unchanged
criteria observe opening/middle/ending on desktop and phone. The one
concept unit includes build/browser work, with 895,000 ms work and 5,000 ms
shutdown grace inside a 900,000 ms child-lifetime envelope, subject to
scheduling jitter. There is no automatic retry or next unit. Interruptions
and unsettled descendants are recorded, not attributed to a guessed sender.
