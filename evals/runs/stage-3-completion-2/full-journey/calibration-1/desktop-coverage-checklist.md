# Expected five-beat desktop calibration coverage

Source-only checklist, prepared during root's one manual-prototype desktop
capture. Not an assertion that the running capture completed. Actual report,
artifact and source checks follow terminal closure. No runtime was started
or modified by this review.

The observed target order is opening.assembly, power.cycle,
middle.relationship, proof.boundaries, close.evidence. This is deliberately
five beats, not the journey's normal 12 to 22. The count mismatch remains a
negative scope observation even if renderer and coverage observations pass.

Expected complete desktop evidence:

- Exact source-before/after equality to the fresh manual copy and saved
  snapshot, digest `1c499ad1346aa437d5701993b7b71f1b60cc35670e9afe0b7c76d48a1c18a060`.
  Original prototype and helper-snapshot identities remain separately bound.
- One reused production build proof, matching immutable `.next` inventory
  before and after this unit, no corrective rebuild or source rewrite.
- Exactly five rests in target order, plus mid and end originals per beat:
  15 PNGs before control and motion evidence. All four recorded positions
  per beat, plus the initial page sample, give 21 DOM samples here because
  this calibration's required link list is empty.
- Four adjacent forward intervals and their four reverse counterparts,
  each with three genuine moving original JPEGs at fractions 0.2, 0.5, 0.8,
  for 24 travel originals. Require completed requestAnimationFrame paths,
  actual directed positions and all eight intervals, not only endpoint images.
- Raw control census at all five rests, plus the dynamic unique actionable
  inventory. Every inventoried ordinary control has pointer and actual Tab/
  keyboard trial records and before/after originals. The predeclared
  focus-only skip has one unfocused pointer original with N/A evidence and
  keyboard before/after originals. No final control count is assumed before
  the report closes; if every ordinary trial completes and there are N
  controls including that one skip, the expected image count is 38 + 4N.
- Whole opening wording is matched in its mapped actual beat with the
  preserved BR/inline word boundaries. Its existing start/mid/end/rest
  samples retain positional visibility coverage. Exact supplied wording,
  missing characters and observer limitations are checked, not inferred
  from source text alone.
- HTTP/errors/failed requests, document order/headings/language/duplicate
  IDs, overflow, scene/canvas presence and semantic-response limits remain
  in the report. The separate control-settlement finding qualifies any
  mid-scroll after-image; no blank-frame failure is inferred here.
- Manifest artifact map exactly matches every retained non-manifest file.
  Every generated PNG/JPG/JPEG, including duplicates of identical bytes,
  receives individual original-detail review with exact path/hash/size.
  Technical result, five-beat count negative, coverage completeness and
  human visual assessment remain separate.
- Root's terminal tool and calibrated bounded-process record show the
  actual exit/signal/deadline state. Desktop work is capped at 475000 ms
  plus at most 5000 ms shutdown, 480000 ms total subject to scheduling jitter.
  An incomplete unit is preserved, never retried or relabelled complete.

This calibration does not run mobile, short, reduced-motion, no-WebGL,
no-JavaScript, context-loss or auxiliary pages. They are unobserved, not
implicitly covered by this desktop calibration. The normal `verify.mjs`
requires a real successful actor binding and the complete stage unit set;
it must not be weakened to pass this deliberately separate calibration.
