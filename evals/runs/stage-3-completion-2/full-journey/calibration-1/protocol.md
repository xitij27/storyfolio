# Prospective local calibration

No model or actor output is used. The copied manual prototype and source
remain unchanged. One offline install precedes one gate capture, one final
build and one desktop capture, each separately invoked with the existing
finite bounds and no automatic retry. The gate has one actual look, so the
unchanged policy must report the two-to-three-look count failure. The final
source has five actual beats, so the unchanged policy must report the
12-to-22-beat count failure. These expected negatives must not be removed
or padded away. Process closure, source integrity, rendering, artifact and
coverage assertions are examined separately. Every emitted original will
be reviewed. This is not a full-journey or Stage 3 pass.
