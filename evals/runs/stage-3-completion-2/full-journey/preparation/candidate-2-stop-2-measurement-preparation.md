## Concrete nested-app limitation, pending completed output

Root reported that the live actor scaffolded into `site/`. That report is
not a final source inventory, and this reviewer did not inspect the live
workspace. If the terminal application remains nested, the frozen apparatus
cannot execute it unchanged:

- `prepare-source.mjs` restores the entire snapshot into a new workspace
  and records that whole root as `work`.
- `run-unit.mjs` requires installation `cwd === prepared.work` and passes
  that same root as the worker's `--workspace`.
- `gate-worker.mjs` resolves package/Next identity and runs build/server
  commands from that root. It has no application-root option.

A missing package at the whole workspace root would therefore prevent the
correct nested application from being measured. Copying only `site/`, moving
its files upward or silently passing a different workspace would violate
the frozen full-source guards. Nested output is permitted by the actor
task: this would be an apparatus limitation, not a skill failure, a
no-output finding or permission to coach the actor into another layout.
