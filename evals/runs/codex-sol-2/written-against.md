agents and Astra medium judges retain their prior roles. Planned coverage

The new wording replaces the existing sentence-only check. It adds no new
file, reference, stop or fixture-specific example. The main description is
unchanged. Each added clause is tied to a recorded miss; ordinary successful
behaviour is not expanded into further instructions.
