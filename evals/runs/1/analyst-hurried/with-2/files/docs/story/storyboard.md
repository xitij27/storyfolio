## The look and the type

**Primary look — "Night pipeline."** Ground: near-black charcoal. Ink: warm off-white. One accent: copper/terracotta, a nod to Lisbon rooftops rather than a default SaaS blue-purple. Node surfaces: dark brushed graphite with thin edge-lit lines.

**Alternate — "Azulejo."** Ground: deep indigo. Ink: chalk white. Accent: gold edge lines. Node surfaces: matte, ceramic-tile-like. Held in reserve; properly chosen by scrolling the built site, not from swatches.

Two typefaces: a humanist grotesk for body text (e.g. Inter or General Sans), and a monospace for anything printed on the pipeline blocks (e.g. IBM Plex Mono) — because the real material of his trade's documents is code and config, which is set in monospace.
