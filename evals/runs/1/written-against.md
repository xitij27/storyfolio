# What each part of the skill answers

The skill's first version, set against `findings.md`. A row for every point
the plan's contract named. A point is in the skill if a finding needs it, or
if it is one of three things no run could show: the names of the files under
`docs/story/`, that this version does not build, and the steps for getting a
profile out of LinkedIn. Otherwise it is left out, and the row says why.
