## What root takes from it

These are root's reading, to be confirmed by the author's reaction to the
examples:

- **Questions to the author come as examples to react to,** not as
  technical choices.
- **An example must be ready to use.** A transition shown to the author
  should go into a portfolio as it is, with only the person's text and data
  changed. The chapter order is fixed (hello, where from, studied, worked,
  good at, made, others say, contact;
  [structure](../superpowers/specs/2026-10-22-portfolio-structure.md)), so
  each seam between two chapters can have ready-made transitions that work
  for any person. The study's seam (one person's data pipeline becoming
  their route) needed a shape found for that one person, which an agent
  would have to invent again for every seam of every site.
